# 任务小帮手

一个适合小学三年级孩子的安静学习工具。MVP 只做“管理今天”：选择任务 → 选择预测时间 → 检查材料 → 3 次完整深呼吸 → 正式开始 → 专注 → 自检 → 对比与复盘。

> 任务小帮手 的目标不是让孩子越来越依赖提醒，而是让家长逐渐退出执行管理。孩子可以继续使用一个越来越轻的外部系统来管理时间、任务和注意力。

“妈妈退出”是目标，“所有工具退出”不是目标。系统随年龄增长逐渐从提醒每一步，变成提供目标、计划、时间和复盘的外部支架。当前集中练习时间预测、执行和对比。

## 运行与部署

需要 Node.js 22.12 或更高版本（开发验证环境为 Node.js 24）。

```sh
npm ci
npm run dev
```

打开 http://localhost:3000。手机/iPad 和电脑连接同一个局域网后，可以访问电脑的局域网 IP:3000（防火墙需要允许）。

儿童端网址为 `/`，家长端独立网址为 `/parent/`（开发时 http://localhost:3000/parent/）。儿童界面没有家长入口链接，也没有添加任务按钮。部署后家长直接收藏 `https://你的域名/parent/`。两端使用同一站点的本机存储。

```sh
npm run lint
npm run typecheck
npm test
npm run build
npm run preview
```

`npm run build` 生成 `out/` 静态网站。将 **out 内全部文件及目录** 上传到自己的域名空间根目录，保留 `_next/` 目录即可。无需 Node 服务、云数据库或 Sites。建议域名启用 HTTPS。部署到子路径时，先在 `next.config.ts` 设置 `basePath`，再构建；默认部署在域名根路径。构建方式参考 [Next.js 静态导出文档](https://nextjs.org/docs/app/guides/static-exports)。

## 已实现

- 首次使用提供三项示例任务；以后每天新建空计划，由家长在独立页面配置任务。
- 儿童首页默认突出前三项任务，其余折叠；新增、编辑、移出计划只在家长端提供。
- 家长在每项任务中填写三个不同的整数分钟选项（1–180）；儿童进入任务页立即看到本任务的三个选择，无自填入口、不预选。旧任务默认 10 / 20 / 30 分钟，可由家长修改。
- 家长在新增/编辑框逐行填写准备材料，支持换行、逗号、顿号并去重；孩子逐项勾选，漏一项不能进入呼吸准备。
- 材料和时间确认后进入 3 次完整深呼吸，每轮慢慢吸气 4 秒、慢慢呼气 4 秒，三轮共 24 秒，不要求屏息；切后台暂停引导，回来接着做。完成后显示“再呼吸一次”和“现在开始”，可额外做一轮 8 秒；仍需主动点击“现在开始”；准备时间不算学习时间。开始前只保留指定提示：“我们努力一次完成。有困难再来找我，我会一直陪着你。”
- 专注页显示任务、计时、必要操作及安静呼吸的小兔子 SVG，不需要联网图片。遵循减少动画偏好。
- 卡住只有三个选项：不认识字 → 使用点读笔；读不懂题目 → 先做下一题；想上厕所 / 喝水 → 先处理再回来。第三项会记录提醒标记，下一个任务准备时必须确认如厕和喝水，正式开始时消费提醒。
- 预测时间到后可完成、再加 5 分钟或记录卡住原因；过程中也可主动完成或记录卡住。
- 自检问题一次只出现一个，按任务类型给出简短提示。通过自检才计为完成。
- 自检通过后一次短暂撒花并显示“恭喜，完成啦！”。按时完成直接让小人走一格；实际时间超过预测时先问“为什么多花了时间？”，只提供四项：比想象中难、中间走神了、有题不会、东西没准备好。选择保存后走一格，再主动回到今天，不自动开始下一项。
- 路径包含起点和与任务数量一致的格子，末尾为小房子；首页、单次结果和今日回顾复用同一个路径。只按任务完成记录定位，不累计点击次数。多任务路径折行，遵循减少动态效果偏好。
- 完成全部任务后进入安静的今日回顾、小路、三个统计和一个日复盘问题（仅今天存在超时任务时出现）。
- 家长端：任务表、材料、主动开始/提醒/卡住统计、提醒标记、过程记录、历史日期查看、JSON 导出。
- 时间戳计时；刷新可恢复专注、自检、复盘状态，后台返回时立即校准时间。跨午夜保留原任务，结束后进入新一天。
- 移动优先、触摸按钮、原生模态框、键盘焦点样式、内容宽度限制与减少动画偏好。

## 产品原则

App 不替孩子思考，而是提示孩子自己做决定。每个页面尽量只做一个决定；时间到不是失败。强化的是对自己的了解，不是聪明、积分或服从。家长的提醒、计时、安排、检查暂时外置，再逐渐交还给孩子。

不加入金币、商城、排行榜、连续打卡、宠物养成、大量动画、每日鸡汤、AI 自动安排、系统预设每项任务时长以及远程监控。计时页的小兔子只提供安静的陪伴，不包含游戏、奖励和养成功能。根据当前需求，自检完成时允许一次 1.8 秒的撒花和一次路径前进，不在专注时播放，不增加连续打卡或养成。

## 架构与数据

Next.js App Router + React + TypeScript + Tailwind CSS；纯静态输出，界面与数据均在浏览器运行。没有外部字体或图片请求。

| 路径                    | 职责                                                    |
| ----------------------- | ------------------------------------------------------- |
| `src/lib/models.ts`     | 集中定义 Zod schema 和 TypeScript 数据类型              |
| `src/lib/flow.ts`       | 纯函数：任务、计时、状态迁移、提醒、复盘                |
| `src/lib/repository.ts` | 唯一持久化边界，版本化 localStorage，校验读写，订阅更新 |
| `src/components/`       | 首页、预测、专注、自检、结果、今日回顾、家长页及表单    |
| `src/app/`              | 页面入口、元信息、响应式样式                            |

核心模型：

- **User**：id、name、stage、preparationReminderNeeded（下一项任务的如厕/喝水提醒）。MVP 单个本地用户 Nora，不要求登录。
- **Task**：id、userId、title、description、type、checkQuestion、plannedDate、priority、createdAt、deletedAt、reminderPending、materials（最多 30 项）、timeOptions（三个不同的可选分钟数）。
- **DailyPlan**：id、userId、date、taskIds、createdAt。一天一份计划。
- **TaskSession**：taskId、date、estimatedMinutes、actualMinutes、extensionCount、startedIndependently、stuckReason、reflectionReason、completed、checkCompleted、startedAt、completedAt，以及任务名称/类型/自检问题快照、targetEndsAt、finishedAt、status、stuckEvents、preparation（已检查材料快照、如厕喝水确认、呼吸开始/完成时间、guidedBreaths、guidedBreathingMs）。
- **Reflection**：关联 sessionId 的单次复盘或按日期的日复盘，包含 reason 或 moreTimeTaskId。

状态：`focusing → checking → reflecting → completed`。点击“做完了”保存 finishedAt 并停止学习计时；自检通过才设置 completed/checkCompleted；按时完成不问原因；超时选择原因后展示前进，主动返回今天才释放当前任务。自检和复盘的时间不计入学习时间。卡住、等待和切后台仍算真实经过时间，MVP 不添加暂停控制。actualMinutes 保留小数，显示精度为 0.1 分钟，不足 1 分钟明确显示。

计时公式：`(finishedAt ?? Date.now()) - startedAt`；剩余时间为 `targetEndsAt - Date.now()`。定时器只触发重绘，不累计秒数。超时后加 5 分钟从 `max(targetEndsAt, now)` 延长，防止孩子晚点击后仍然超时。

历史可以计算：预测比值 `estimatedMinutes / actualMinutes`（actualMinutes=0 时排除）、误差 `abs(actual-estimated)/actual`、自主启动比例、延时次数、卡住事件及任务类型。完成任务被移出计划后，其 session 与快照仍保留，家长记录也会显示。已经开始的任务不能改写名称和类型，避免污染学习过程；可新增下一项。

首次加载和每次更新均校验 schema，写入成功后才更新 UI；无法读取时保留原始记录并提供原始导出，不静默重置。其它标签页的有效变更可同步。未来数据库迁移替换 Repository，保留纯业务函数与版本化 schema；需要增加异步接口和迁移程序时再做。

## 提醒与存储边界

默认 startedIndependently=true；家长开始前勾选“提醒后开始”，开始时读取 reminderPending；也可以事后更正。它是家庭自报记录，没有暗中监控。家长端无密码，独立网址只是入口分离，不是身份验证或远程家长账号。

新增字段采用 schema 默认值兼容旧记录；旧版卡住原因仍可读取和导出，儿童端只提供新的三个选项。准备阶段刷新后返回任务选择，并重新检查材料和深呼吸；正式开始后保存 preparation 快照。新字段保留 version: 1 的向后兼容扩展：缺少 timeOptions 时补 [10,20,30]，旧准备快照补 guidedBreaths=0、guidedBreathingMs=0，旧复盘六项仍可读取。`startPreparedTask` 在数据层校验本任务的时间选项、全部材料、如厕喝水提醒、至少 3 轮且至少 24 秒的有效引导时间，防止绕过步骤或另一标签页修改材料后错误开始。

数据仅存在当前设备、当前浏览器和当前站点域名的 localStorage；刷新不会丢失，但清理网站数据、隐私模式、换域名或换设备不会自动同步。家长可导出全量 JSON 备份；MVP 未实现导入。导出保留所有历史和版本号，便于后续迁移。浏览器不运行时不会主动通知，但再次打开会恢复真实计时。系统时钟改变会影响时间戳计时。

本次 lint、typecheck、test 和静态 build 均通过。生产依赖 `npm audit --omit=dev` 为 0 项；开发期的 Next.js ESLint 依赖链存在 5 项 high 报告（braces 及传递依赖，当前 registry 没有补丁版本）。它们不进入 `out` 静态产物；未采用会降级 Next.js 配套检查器的强制修复。后续维护应跟进上游更新。

新增测试覆盖吸气/呼气三轮阶段、后台引导暂停、额外一轮、每项任务时间配置与旧选项失效、旧记录默认值、仅超时询问原因、原因保存与刷新、路径单次前进和抵达小房子。

本次在 390×844 的手机视口实操验证：每项任务显示各自的三个时间，三轮呼吸、额外一轮与开始门槛，按时完成不问原因，实际一分钟超时后仅显示四个原因，选原因前进与刷新后仍保持两格，不自动进入下一任务。

此前浏览器实操验证：独立家长网址、儿童端没有家长和添加入口、材料逐行保存与去重、少勾一项不能准备、3 轮完成前不能开始、三种卡住原因及对应提示、专注刷新恢复、下一任务的如厕/喝水确认。旧版已验证的自检、结果、历史与 JSON 下载继续保留。截图保存在 `docs/`。未在真实 iPhone Safari 设备上测试。

实际操作检查建议：家长设置材料 → 儿童选择时间 → 逐项检查 → 3 次完整深呼吸 → 现在开始 → 刷新 → 记录卡住 → 完成 → 自检 → 复盘 → 下一任务查看提醒。超时与延长由自动测试验证，不需等待完整 10 分钟。使用 Safari 真机进一步检查安全区域、后台恢复和备份下载。

## 暂不实现与下一阶段

账号、云同步、通知、周计划、长期任务拆分、复杂分析与权限均未加入。Stage 1 先观察真实使用；下一阶段优先用真实使用反馈调整时间选项和提示密度，继续培养时间规划能力。Stage 2 拖动安排一周；Stage 3 用提问帮助拆解长期任务；Stage 4 逐步形成目标 → 计划 → 学习 → 自测 → 发现漏洞 → 调整方法 → 重新测试的 Learning OS。每一阶段都应让孩子作决定。



## 积分与任务模板（2026-10-07）

每项任务完成并自检后，立即获得1分基础分；当日全部任务走完到小房子，额外加2分（每天只计算一份，不随刷新重复累加）。这份奖励写入计划，之后临时追加任务不撤销、不再次发放。超时任务需先选择原因，才前进到小房子并获得全部完成奖励。学生端右上角显示累计积分，专注页不显示积分。

家长检查后选择正确情况，并点击“提交积分修改”才更新：全对将该项基础1分改为2分（不叠加），错误不超过四分之一保留1分，超过四分之一改为0分。仅切换选项不改积分；允许更正，重复提交不重复计分。当日全部完成的额外2分不因正确率调整撤销。家长未检查时已发基础分，家长端显示待确认，不猜测正确率。

当天有任务但0:00未走到小房子扣1分；空计划不扣。页面运行时按本机下一次0:00安排结算，同时保留日期轮询和回到页面时校正；浏览器关闭或后台暂停时，下次恢复或打开补结算。每日扣分固定且最多一次，允许总积分为负。启用前的历史日期不追扣。跨午夜的任务仍能继续，次日补完成不撤销上一日已结算的扣分。首次在新日期打开时才激活旧数据的积分，不把早期历史任务计入积分。家长晚些检查仍可调整对应任务得分。

家长新增/编辑任务时可勾选“保存为模板”，也能从已有任务保存。模板保留名称、说明、类型、重要程度、材料和三个时间选项；下次选择模板点“添加到今天”，生成独立的新任务和新session，不复制成绩、提醒和完成状态。同一天相同名称和类型不重复导入。重复保存同名同类型模板更新设置；删除模板不会删除已安排任务或历史session。

旧localStorage键和version:1保留，通过schema默认值补充 templates=[]、scoringStartedOn=null、session.quality=null、plan.dailyPenalty=null、plan.completionBonus=0。已有任务、家长评分和每日扣分保留；已启用积分的记录按新基础分及奖励规则计算，未启用前的历史不计分。没有自动清空、账号、云同步或额外依赖。

积分测试覆盖旧数据兼容、完成即发基础分、2/1/0分更正且不重复计分、自检前不得分、全部完成额外2分及家长调整保留奖励、超时先选原因再发奖励、0:00边界与单次扣分、空日无奖励或扣分、跨午夜session保留，以及模板复制、重复导入和删除隔离。
